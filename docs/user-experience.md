# 对话与交付体验

先利用已有事实，再问一个真正影响结果的问题。反问的目的，是减少猜测与返工；输入完整时直接推进。

| 场景 | 应怎样回应 | 为什么要问 |
| --- | --- | --- |
| “这张表达矩阵帮我做差异分析” | “这里的值是原始 read/fragment 计数，还是 TPM/FPKM？整数外观不能确定来源。请补充生成矩阵的工具与输出类型；若是原始计数，可继续检查分组设计。” | 数据含义决定能否使用计数模型 |
| 只有分组，没有样本关系 | “每一列来自独立生物学样本，还是同一样本的重复测量？请补一张 sample_id、condition、biological_unit、batch 表；后两列未知可写未知。” | 技术重复不能冒充独立生物学重复 |
| 处理组和批次完全重合 | “当前表里处理组都在批次 A，对照组都在批次 B，无法区分处理效应和批次效应。是否有跨批次的同组样本？若没有，可先做描述性 QC，不能把调整批次视为解决办法。” | 明确可识别性限制，并给出可继续的路径 |
| “用全基因组当背景做 ORA” | “这些基因是否都有机会进入你的显著名单？建议用实际进入筛选的可检验基因作为背景，请提供这份列表或原始结果表。” | 背景选择直接改变富集结果 |
| “拿显著基因做 GSEA” | “排序富集看完整排序的两端，只有显著基因会改变问题。请提供完整可用的带符号统计量；例如已声明比较方向的 Wald statistic。” | ORA 的选中列表与 GSEA 的完整排序不同 |
| “这张 PCA 证明处理有效” | “图中分离说明所展示投影上的表达差异，尚不能确认来自处理。先核对批次、文库和异常样本，再结合预先指定的比较解释。” | 图形模式不是因果证明 |
| “p > 0.05，所以没有作用” | “没有达到阈值不等于没有效应。一起看效应量、区间和样本量；目前能说的是证据不足以支持该阈值下的差异。” | 防止把不显著误解为无效 |

## 问题的结构

一句观察 + 一句影响 + 一个明确问题/最小补充格式。推荐方法可以给，未知研究事实不能代填。
对于尚未确认的疑点用“可能”，对于文件中已确认的矛盾说明依据。用户更正后保留原始数据，记录采用的变换或排除规则。

每次只推进最关键的一项决定。相互关联的缺失字段可以放在一张小表里补充，不要机械地每列问一轮。等答案期间继续不依赖该答案的授权工作。
如果用户不知道，优先查已有元数据；仍无法确定时给出边界清楚的探索性输出。不要强迫用户猜答案，不要重复已解决的问题。

术语第一次影响决策时解释中英文含义；对熟练用户保持简短。不要把每次操作变成问卷、术语课或确认会。

## 图表与交付

- 火山图：效应方向、幅度与显著性；明确原始/校正 p 值及阈值。
- PCA：样本结构与异常线索；注明变换、所用基因和解释方差。
- 热图：小范围表达模式；注明缩放与行列顺序。
- 报告：先给步骤状态和关键数量，再给图、数据、参数与限制。

图表保留 PNG、SVG 与绘图数据。只做能回答当前问题的图；简单查 ID 不必作图。
报告中某一步未完成，就明确标出，不能因为报告文件生成成功而把分析写成完成。

这些是经过静态内容审阅的行为规范；本轮没有运行 Agent 对照实验。
