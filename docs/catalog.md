# Candidate capability catalog

This is a research map, not a release promise. Final Skill boundaries will be decided after source repositories are modeled and clustered.

## Cross-cutting candidates

- bioinformatics workflow reproducibility audit
- bioinformatics tool and interface freshness audit
- reference genome and annotation compatibility check
- sample sheet and metadata quality review
- workflow provenance and methods-report generation

## Transcriptomics candidates

- bulk RNA-seq experimental-design review
- bulk RNA-seq preprocessing and QC triage
- differential-expression analysis planning and review
- single-cell raw-count QC and filtering review
- single-cell normalization and feature-selection planning
- single-cell integration and batch-effect assessment
- single-cell cell-type annotation evidence review
- single-cell differential-state analysis review
- spatial transcriptomics QC and analysis planning

## Genomics and epigenomics candidates

- germline or somatic variant workflow review
- variant annotation and reference compatibility audit
- ChIP-seq or CUT&Tag QC and peak-analysis review
- ATAC-seq QC and accessibility-analysis review

## Other likely families

- metagenomics workflow and database-selection review
- proteomics QC and differential-abundance review
- sequence search, alignment, and phylogenetic workflow review
- structural bioinformatics and molecular-modeling workflow review

The default is to split scientific planning, execution, QC interpretation, and biological interpretation when combining them would hide distinct inputs, risks, or evaluation standards.
