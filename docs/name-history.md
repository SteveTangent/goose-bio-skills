# Name history

This project was renamed from **Bio 02 Skills** (`02-bio-skills`) to
**Goose Bio Skills** (`goose-bio-skills`) on 2026-08-17. It remains the same
repository and Git history; the rename did not create a fork or replacement
project.

## Compatibility policy

- Current documentation and clone instructions use `goose-bio-skills`.
- Existing commits, tags, releases, package versions, and evidence records are
  not rewritten.
- Historical `bio02-*` fixture, schema, command, and report identifiers remain
  stable so their hashes and references continue to resolve.
- Package-contained compatibility names change only in a future package release
  when their public contract requires it; a repository rename alone does not
  alter package bytes.
- The former GitHub location is retained only as GitHub's repository redirect.
  The old repository name must not be reused, because doing so would break that
  redirect.
