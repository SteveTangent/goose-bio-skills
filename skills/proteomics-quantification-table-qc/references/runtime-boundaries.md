# Runtime boundaries

Current 0.13.0 adds a standard-library protein-table helper. Read the
[local adapter](local-adapter.md) for its bounded executable path and small
checks. Peptide/protein-group objects, large tables, QFeatures/MSstats and raw
spectra remain guidance-only/unexecuted. They are not implied by helper success.
No Agent runtime evaluation, scientific benchmark or human expert review was
performed. Declared release status remains preview + reviewed.
