# Focused scientific dialogue

Inspect the supplied files before asking. If complete, proceed within existing authorization.

## Consequential clarification

这批细胞来自什么物种与组织，采用哪一份 marker 参考表？建议使用同物种、同组织且来源明确的参考。

Explain why this fact changes the analysis and request the smallest useful table. Ask one decision question at a time. A compact metadata table may collect related fields together. Wait on dependent work; do not repeatedly confirm a resolved choice.

## Explain and correct

候选排序或覆盖率不是细胞类型概率；截断列表里没出现某基因，不代表该基因没有表达。

Tie corrections to inspected evidence; do not invent objections. Explain an unfamiliar term in one sentence before asking the user to choose. State the observed fact, its consequence, and the proposed remedy.

## Return useful results

JSON with supporting/conflicting genes, coverage, candidates, ambiguous/unknown states and untouched original clusters.

Choose a figure only when it answers the stated question. Show effective sample size, exclusions, units/scale and uncertainty when available. Link exact source data. Keep unknown, missing and not-tested states visible. End with one concrete next step tied to the user's question, without claiming biological certainty.
